# 功能規格：響應式畫面與穩定球拍控制

## 問題

1. 遊戲介面在一般筆電或低高度螢幕上過大，需要大量捲動才能看完整個畫面。
2. 玩家球拍會因滑鼠游標只是經過 Canvas 就開始追蹤，且鍵盤放開後可能回到舊的游標位置，造成跳動感。

## 目標

- 1366×768 等一般筆電尺寸可在不放大瀏覽器的情況下舒適遊玩。
- 手機直向與低高度橫向螢幕都有專用壓縮版面。
- 滑鼠／觸控改為「按住拖曳」才控制球拍；單純 hover 不應移動球拍。
- 鍵盤 W/S、方向鍵與畫面上下按鈕維持可用。
- 鍵盤輸入時不會被先前的滑鼠目標拉回。
- GitHub Pages 的 `docs/` 發布副本與根目錄保持一致。

## 驗收條件

- CI smoke test 驗證新的響應式 CSS 與控制修正腳本均被載入。
- CI 驗證 `docs/` 中的新檔案與根目錄完全同步。
- 不更改得分、球速、AI 難度或碰撞規則。
