# 快速驗收：NEON ARENA｜Cyber Pong

## 自動檢查

在專案根目錄執行：

```bash
npm test
node --check game.js
```

預期：煙霧測試全部顯示 `✓`，Node 語法檢查無輸出且回傳成功。

## 手動情境

1. 開啟 `index.html`，確認 NEON ARENA 入口、比分板與球桌可見。
2. 點擊「開始比賽」，確認 3、2、1、GO 倒數與第一球發出。
3. 用 `W`、`S`、上下方向鍵移動左側球拍，確認球拍不會離開球桌。
4. 將指標移入球桌上下移動，確認滑鼠／觸控控制生效。
5. 分別切換「新秀」「職業」「菁英」，確認按鈕狀態更新且 CPU 追蹤手感不同。
6. 點擊暫停按鈕或按空白鍵，確認球、AI 與粒子停止；再次操作後恢復。
7. 讓任一方得分，確認比分、回合數與發球方向更新。
8. 讓一方達到 7 分，確認勝負結果、再次挑戰按鈕與局末狀態。
9. 完成一次連擊後重新整理頁面，確認「最佳連擊」「最快球速」仍保留。
10. 在手機寬度查看，確認球桌、比分與控制面板不溢出。
